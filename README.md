# THE TRIPS WAY

Premium travel affiliate landing/web V1, built with React + TypeScript + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Vercel

Import the repository into Vercel. Framework preset: Vite. Build command: `npm run build`; output directory: `dist`.

## Travelpayouts

The site currently includes a visual widget slot. Replace that slot with the official Travelpayouts widget code once the website project is approved and the widget code is available. Do not paste unverified or invented widget code.
